Cutline bundles the following third-party components.

--------------------------------------------------------------------------------
FFmpeg / FFprobe
--------------------------------------------------------------------------------
Cutline bundles a static Windows build of FFmpeg (which includes FFprobe),
built by gyan.dev (https://www.gyan.dev/ffmpeg/builds/), distributed via the
npm packages `ffmpeg-static` and `ffprobe-static`.

This build includes libx264 and libx265 and is therefore licensed under the
GNU General Public License version 3 (GPLv3). Full license text:
https://www.gnu.org/licenses/gpl-3.0.html

FFmpeg source code: https://github.com/FFmpeg/FFmpeg
FFmpeg project: https://ffmpeg.org
